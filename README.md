# ApnaVault

Apni photos, videos aur files ka personal vault — Telegram me safe, unlimited aur free.

Pehli baar kholne par "Telegram jodo" page aayega. Wahan apna Telegram account connect karo.
Uske baad jo key mile, usse Space ke Settings → Variables and secrets me `TG_CONFIG` naam se
add kar do — taaki restart par bhi juda rahe.
